# 设计上下文 — 短视频下载工具（douyin-tool）

> 本文件是 impeccable 设计技能的项目设计上下文，后续所有界面设计工作以此为准。

## Target audience

内容创作者、新媒体运营、二次剪辑用户。他们在 Windows 桌面端使用本工具，
核心诉求是**快速、批量、无水印**地保存抖音/快手视频，追求效率而非探索。

## Use cases

1. **单个下载**：粘贴分享链接 → 解析 → （迅雷/直接）下载 → 复制/导出视频文案
2. **批量下载**：粘贴抖音用户主页链接 → 解析作品列表 → 勾选 → 批量下载 → 打开保存目录
3. **辅助操作**：更换保存位置、切换深浅主题

## Brand personality / tone

**「深色霓虹影院」**——视频工具应有沉浸感与品牌归属感：

- 默认深色主题（非纯黑，偏蓝墨色 #0b0d13），可一键切换浅色
- 抖音品牌红 #fe2c55 作主行动色，青光 #25f4ee 仅作点缀（辉光、焦点环、渐变细节）
- 品牌标志与标题使用红青错位（故障艺术）效果，致敬抖音视觉基因
- 语气：专业工具感，文案极简，无装饰性废话

## 关键设计决策

- 每个视图**只有一个主按钮**（红色渐变填充），其余为描边/幽灵按钮
- 批量作品使用**封面网格**而非列表——视频内容以封面为先，整卡可点选
- 底部保存位置采用**悬浮胶囊状态栏**（sticky + backdrop blur），常驻但不占位
- 动效一律 `cubic-bezier(0.16, 1, 0.3, 1)` 指数缓出，150–320ms，尊重 prefers-reduced-motion
- 无 emoji 图标，统一 `src/components/icons.tsx` 描边 SVG（1.8px / currentColor）
- 设计 token 全部集中在 `src/App.css` 的 `:root` 与 `[data-theme="light"]`，改色只动 token

## 技术约束

- Tauri v2 + React 18 + Vite，Windows WebView2（现代 Chromium，支持 color-mix / backdrop-filter / aspect-ratio）
- 离线桌面应用，**不使用任何外部 Web 字体/CDN**，字体走系统栈（PingFang SC / Microsoft YaHei）
- 主题持久化：localStorage `dy-theme`，首屏防闪烁脚本在 index.html <head>
