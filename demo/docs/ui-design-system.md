# 短视频下载工具 · UI 设计方案

**方向**：深色霓虹影院（默认深色）+ 一键切换浅色 · **状态**：已实现并构建验证
**设计/实现**：UI Designer · 2026-07-25

---

## 1. 设计目标

| 目标 | 落地方式 |
|------|---------|
| 美观、有品牌记忆点 | 抖音红/青双色霓虹体系 + 故障艺术 Logo/标题 |
| 易用、符合用户习惯 | 单/批量双模式、每视图一个主按钮、三步流程引导、整卡点选 |
| 一致、可维护 | 全部视觉决策收敛为设计 Token，组件化图标与基础控件 |

## 2. 设计 Token 系统（`src/App.css`）

- **色彩**：深色底为偏蓝墨色 `#0b0d13`（非纯黑）；品牌红 `#fe2c55` / 青光 `#25f4ee` 克制点缀；
  语义色 success/danger/thunder（迅雷蓝）/kuaishou（快手橙）各有 soft 底色版本；
  文字三级 `--text / --text-2 / --text-3` 在各自表面上对比度 ≥ 4.5:1（WCAG AA）
- **表面层级**：`--bg`（页面）→ `--bg-elev`（面板）→ `--bg-sunken`（输入/凹槽），
  配合 `--border / --border-strong` 与两档阴影，深浅主题各自取值
- **圆角**：8 / 12 / 16 三级；**动效**：`cubic-bezier(0.16,1,0.3,1)`，150–320ms
- **主题机制**：`:root` 深色 token + `[data-theme="light"]` 全量覆盖；
  `localStorage("dy-theme")` 持久化，`index.html` 内联脚本首屏前恢复，零闪烁

## 3. 界面结构

```
┌ 顶栏：故障艺术 Logo + 标题 + 副标语 ············ 主题切换（日/月）
├ 分段控制器：单个下载 / 批量下载（红色滑块指示器，滑动切换）
├ 主区域
│ ├─ 单个下载：链接输入面板（平台徽章 + 三步引导）→ 错误横幅
│ │            → 结果卡片（3:4 封面+时长角标｜标题｜作者｜进度｜文案块｜操作）
│ └─ 批量下载：主页链接面板 → 批量进度卡片（进度条 + 成功/失败徽章）
│              → 工具栏（全选 + 下载选中）→ 封面网格（3:4 卡片，整卡点选）
│              → 空状态引导
└ 底部：悬浮胶囊状态栏（保存位置，常驻、毛玻璃、路径尾部优先截断）
```

## 4. 关键交互

- **批量网格整卡即复选框**：点击/Enter/Space 切换选中（`role="checkbox"` + `aria-checked`），
  选中态 = 红色描边 + 辉光 + 勾选圆点；下载中/已完成/失败在封面上显示毛玻璃状态蒙层
- **进度条**：红色渐变 + 流光动画；未知总长时进入不定态滑动；批量进度带成功/失败计数徽章
- **按钮层级**：主按钮 = 红色渐变填充 + 辉光（每视图唯一）；次要 = 幽灵描边；迅雷 = 蓝色描边；
  hover 上浮 1px、active 回弹、`:focus-visible` 可见焦点环
- **空态教育**：单视频未解析时显示「① 粘贴链接 ② 解析信息 ③ 下载无水印」；
  批量未解析时显示插图化空状态
- **无障碍**：全部交互可键盘到达、焦点环清晰、图标按钮带 aria-label、
  进度条 `role="progressbar"`、错误 `role="alert"`、`prefers-reduced-motion` 全量降级
